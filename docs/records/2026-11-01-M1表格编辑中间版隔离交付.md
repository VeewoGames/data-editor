# M1 表格编辑中间版隔离交付

## 方案概述

本阶段按用户批准的范围，交付一个已经构建并完成有限整合验收的前端中间版，结束本轮无期限性能试验。流程为：冻结357前端来源与当前正式工作树→整合运行依赖和正式后续功能→实际页面与数据安全回归→冻结变更包和遗留边界。正式源码、正式业务数据、部署和用户authority没有激活或迁移；没有Git提交或推送。

**交付版本：`M1-frontend-2026-11-01`。独立复核：`ready-for-intermediate-delivery`。** 这是可审阅的源码/构建差异交付包，不是整版无历史迁移，也不是一键安装器。正式激活继续单独确认。

设计师视角：本版把已验证的编辑、加载作用域和普通失焦局部改进落实为可交付产物，保留现有操作、自然行高、数字选项类型、800ms自动保存和完整文档协议。大表滚动及完整保存耗时仍可能明显，真实Windows输入法未验；这些留到后续，不再阻塞本中间包交付。

## 实际纳入内容

- 以 `frontend-row-projection-validation` 的浏览器运行依赖为主体，连同必要声明共224项参与整合，而非覆盖其完整目录。
- 从原正式源码冻结清单验证共同来源，再把正式工作树后续10项改动三方合入。保留数字/数字形字符串选项的原始JSON类型、空来源元数据及歧义拒绝能力。初次以过旧Git HEAD作共同来源产生的大量冲突没有采用，失败整合证据保留；最终共同来源由原SHA验证。
- React Virtual 3.14.23 / Virtual Core 3.19.8进入正式package/lock依赖，清除对task相邻目录的引用。全新`npm ci --ignore-scripts`、TypeScript和Vite生产构建通过；大chunk提示保留，不通过调高阈值掩盖。
- 修复一次真实组合兼容问题：多文件主键同步部分成功后，显式重试使用已成功路径的实际ACK版本。原确认root不变，scope/revision/baseline守卫保留，不跳过版本检查，不新增编辑操作、自动重放或界面状态。
- 将6项通用保存回归移交到包内 `tests/release`，命令为 `npm run test:m1`。不依赖task路径或游戏项目数据；测试副本单独隔离authority、项目和registry，实际核对served HTML/JS。
